#	Exult shaded light table for Black Gate.
#
#	How each light source lights the world when the shaded light renderer
#	(config/video/shaded_light/enabled) is on.  Rows only apply to objects
#	the engine already treats as lights, that is shapes with a light_data
#	row in shape_info.txt (or the light flag); a mod makes a new light
#	source there, as before, and tunes it here.
#
#	A mod overrides rows with its own <PATCH>/shaded_light.txt, which only
#	needs the rows it changes (same shape and frame replace a row here).
#
#	Format
#		:shape/frame/radius/brightness/red/green/blue/height/flags
#
#	frame		-1 = every frame not listed for that shape.  Frames are
#				matched after masking with 31, as for light_data.
#	radius		In tiles.
#	brightness	Percent; 100 = a torch.
#	red/green/blue	Colour of the light, 0-255.  Only used where the
#				renderer can show colour (the full-colour light
#				overlay); the 8-bit path uses brightness only.
#	height		Lifts above the object's base; -1 = top of its 3D box.
#	flags		Sum of: 1 = area light (even light over its radius,
#				horizontal distance only, lighting surfaces from its
#				lift to 6 lifts above), 2 = off (the shape gives no
#				shaded light).
#
#	Every light starts from the formula, where b is the shape's
#	light_data brightness for that frame (candle 1, torch 5, lamp 7):
#		radius 3 + b, brightness 50 + 10 * b, colour 255/214/170,
#		height -1, flags 0.
#	Lights without a row use it as it is.  In a row, a field left blank
#	(nothing between its slashes) keeps the formula's value, and so do
#	fields left out at the end of the row; only the fields a row sets
#	replace it.  -1 is a value, not "blank": it means -1 where the field
#	allows it (frame, height).  So
#		:526/-1
#	is a lamp lit by the formula, and
#		:1013/-1//140/217/235/255
#	keeps the formula's radius, sets brightness 140 and a cool colour.
#	The Radius and Brightness sliders scale every light, rows included.
#

%%section magic
#	Light spells.  With shaded light on, Light and Great Light do not turn
#	the whole screen to daylight (the palette Exult uses without it).  The
#	clock keeps its own ambient, night stays night, and the Avatar carries
#	a light with a radius instead.  Shadows block it and it moves with the
#	Avatar, as a carried torch does.  No palette is chosen for the spell, so
#	the colour and sun work built on shaded light see the ambient unchanged.
#
#	Format
#		:kind/radius/brightness/red/green/blue/height/flags
#
#	kind		0 = Light (In Lor), 1 = Great Light (Vas Lor).  The spell
#				lasts as long as it does without shaded light.
#	The other fields are as in the lights section (radius in tiles,
#				brightness in percent with 100 = a torch).  The light is
#				always at about hand height, so height is ignored.
#
#	Change the radius to taste.
:0/6/140/217/235/255/-1/0
:1/12/180/217/235/255/-1/0
%%endsection
%%section volumes
#	Rounded volumes: the shape the shaded light renderer gives an object's
#	pixels (config/video/shaded_light/rounded; off = every object its 3D
#	box).  A rounded volume is fitted to the object's 3D box and to the
#	silhouette of its art, so its heights rise towards the middle of the
#	shape and its surface turns smoothly towards the lights; its shadow is
#	that volume, not the box.
#
#	Format
#		:shape/frame/kind
#
#	frame		-1 = every frame not listed for that shape; frames are
#				matched after masking with 31.
#	kind		0 = box, 1 = figure (vertical capsule: people),
#				2 = round (ellipsoid: bushes, rocks), 3 = upright
#				(cylinder with a rounded top: barrels, pillars,
#				dead trees), 4 = tree (trunk capsule under a crown).
#
#	Without a row, actors (NPCs, the party, monsters) are figures and
#	everything else is its box.  A row overrides both ways: a mod's
#	<PATCH>/shaded_light.txt can make a statue a figure (kind 1) or an
#	actor shape a box (kind 0), and only needs the rows it changes.
